# CLAUDE.md

Francis: senior home lending specialist (Melbourne), property investor, runs @FinancewithFrancis on Instagram. Australian context by default.

## What this repo is

Mostly a home for Claude skills and brand context, not an app.

- `.claude/skills/`: skills (Instagram `ig-*`, brand voice, content, real estate, AU tax, Obsidian, visuals)
- `.agents/instagram/voice.md`: Francis's voice. Read it before writing any Instagram content.
- `.agents/product-marketing-context.md`: audience, positioning and compliance guardrails
- `src/`: static site

## Working rules

- Do what was asked, nothing more. Prefer editing existing files over creating new ones.
- Work inline. Don't spawn subagents or parallel agents unless Francis asks for it.
- Keep answers short. Lead with the answer.
- Australian spelling, no em dashes, no Oxford commas.
- Search the web for any current rate, threshold, grant or policy figure. Never quote them from memory.
- Never commit secrets or `.env` files.
